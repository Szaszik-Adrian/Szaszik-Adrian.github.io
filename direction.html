My Direction

Software Engineering

Software Engineering is about designing, building, testing and maintaining software. Software engineers first understand what users need. They then plan the application and write the code. Their work also includes databases, security, fixing errors and updating existing applications.

For a cinema booking system, this means managing films, screenings and reservations. Tests can check that bookings work correctly and screenings do not overlap. Possible careers include web application developer, front-end developer and embedded software engineer.

Data Science

Data Science uses data to answer questions and support decisions. It combines programming, statistics and machine learning. Data scientists clean data, analyse patterns and build prediction models. They explain their results using charts and reports. Common tools include Python and SQL.

For a cinema, this could mean using past booking data to predict visitor numbers and help plan screenings. Predictions must be checked because they can be wrong. Data quality and the privacy of customer information are also important. Possible careers include data scientist and data analyst.

The main difference

Both fields involve programming and problem-solving. Software Engineering focuses on developing reliable applications. Data Science focuses on finding useful information in data and using it to support decisions. These fields can also work together in the same project.

My choice

I prefer Software Engineering because I enjoy building applications and seeing them work. In SilverMozi, I worked on the C# desktop application and used a MySQL database. This gave me practical experience in software development.

I want to build on this experience at HZ. My goal is to become a software developer with strong testing skills. I want to improve my software design, learn automated testing and become better at organising larger applications.
